# Mohamed Mahdy — ArchViz & AI Portfolio

Static portfolio website ready for GitHub Pages.

## Publish
1. Create a repository named `YOUR-USERNAME.github.io`.
2. Upload the **contents of this folder** to the repository root.
3. Go to Settings → Pages → Deploy from branch → `main` / `(root)`.
4. Open `https://YOUR-USERNAME.github.io`.

The included PDF is the optimized portfolio version. Project images are web-optimized JPGs.
